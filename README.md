# fast financial
an up-to-quick way to start a financial tender custodian for banking

## tech
- [vfaas.net](https://vfaas.net) FaaS personal server

### novelty
- sinusodial credit: allows users to get credit on a wave function, to align with periodic spikes in customer cash demand. allows there to be less risk on bank (staggered invidiual customer timings) and users via rate.
- gift cards: offered from a bank, like a stipend.
